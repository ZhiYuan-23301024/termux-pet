========================================
      Termux Pet 终端宠物 (Starship版)
========================================

一、项目简介
-----------
Termux Pet 是一个基于 Starship 的终端宠物系统，具有以下特点：
- 使用 Starship 提示符显示宠物（单行字符画表情包+对话）
- 不再使用子shell渲染，不影响终端操作
- 宠物显示在提示符左侧，不遮挡命令输入
- 心情系统，表情和对话根据命令执行结果变化

二、安装前提
-----------
1. 已安装 Starship
   curl -sS https://starship.rs/install.sh | sh

2. 确保 shell 配置文件中有 Starship 初始化
   eval "$(starship init bash)"  # bash
   eval "$(starship init zsh)"   # zsh

三、安装方法
-----------
1. 将项目文件复制到 Termux 中
2. 进入项目目录：
   cd /path/to/termux-pet
3. 执行安装脚本：
   bash install.sh install
4. 重启终端或执行：
   source ~/.bashrc

四、基本命令
-----------
pets show     - 显示宠物
pets hide     - 隐藏宠物
pets toggle   - 切换显示状态
pets status   - 查看当前状态
pets mood     - 设置心情 (happy/normal/sad/sleeping/eating/working)
pets dialogue - 随机对话

五、心情系统
-------------
心情根据上一条命令的执行结果自动决定：

**命令成功执行 (exit code = 0):**
- 70% 概率：happy (开心)
- 20% 概率：normal (普通)
- 10% 概率：working (工作)

**命令执行失败 (exit code != 0):**
- 60% 概率：sad (难过)
- 20% 概率：normal (普通)
- 20% 概率：sleeping (睡觉)

六、表情+对话系统
-----------------
每次执行命令后，提示符左侧显示宠物表情和对话：

示例效果：
```
[ (^▽^) Nice work! ] user@host ~/path $
[ (´・ω・\`) Don't give up... ] user@host ~/path $
[ (-ω-)zzZ Zzz~ sweet dreams ] user@host ~/path $
```

对话根据当前心情从语料库中随机选取。

七、表情包系统
-------------
表情包存储在 pet_arts.txt，支持6种心情：
- normal   : 普通表情
- happy    : 开心表情
- sad      : 难过表情
- sleeping : 睡觉表情
- eating   : 吃东西表情
- working  : 工作表情

每种心情可配置多个表情，随机选取显示。

八、对话语料库
-------------
对话存储在 dialogues.txt，格式：
```
[mood=happy]Nice work!
[mood=happy]Great job!
[mood=sad]Don't give up, try again
...
```

支持6种心情的对话，可自行添加修改。

九、配置自定义
-------------
配置文件位置：~/.termux-pet/pet.conf

可修改项：
- PET_NAME: 宠物名称

十、Starship 配置
----------------
宠物模块配置位置：~/.config/starship.toml

[custom.petshow] 模块控制宠物显示：
- command: 执行的脚本路径
- when: 显示条件
- format: 显示格式
- style: 样式（颜色等）

十一、文件结构
--------------
termux-pet/
├── pet_state.sh      # 核心状态管理
├── pet_prompt.sh     # Starship调用脚本
├── pet_arts.txt      # 单行表情包库
├── dialogues.txt     # 对话语料库
├── pet.conf          # 配置文件
├── starship_pet.toml # Starship模块配置
├── install.sh        # 安装脚本
└── uninstall.sh     # 卸载脚本

十二、卸载方法
-------------
执行卸载脚本：
bash uninstall.sh
