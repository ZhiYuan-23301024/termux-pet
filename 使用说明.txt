========================================
      Termux Pet 终端宠物交互系统
              使用说明
========================================

一、项目简介
-----------
Termux Pet 是一个基于 Termux 环境的终端宠物交互系统，具有以下特点：
- 字符画宠物显示（cowsay风格）
- 随机对话系统
- 好感度进度条
- 支持 bash/zsh 终端环境

二、安装方法
-----------
1. 将项目文件复制到 Termux 中
2. 进入项目目录：
   cd /path/to/termux-pet
3. 执行安装脚本：
   bash install.sh install
4. 重启终端或执行：
   source ~/.bashrc

三、基本命令
-----------
petshow        - 显示宠物和好感度
pethide        - 隐藏宠物
pettoggle      - 切换显示状态
petstatus      - 查看当前状态
petlove        - 手动增加好感度
petreset       - 重置好感度为0

四、好感度系统
-------------
- 初始值：0
- 上限值：100
- 每次命令执行后自动+1
- 达到上限后不再增加
- 使用 'petlove' 可手动增加

五、配置自定义
-------------
配置文件位置：~/.termux-pet/pet.conf
可修改项：
- SHOW_COMMAND: 显示命令（默认: petshow）
- HIDE_COMMAND: 隐藏命令（默认: pethide）
- PET_NAME: 宠物名称（默认: 小宠物）
- FAVORITE_MAX: 好感度上限（默认: 100）
- FAVORITE_INCREMENT: 每次增加量（默认: 1）

六、对话内容自定义
-----------------
对话文件位置：~/.termux-pet/dialogues.txt
每行一条对话，自动随机选取显示
可自行添加或修改对话内容

七、卸载方法
-----------
执行卸载脚本：
bash uninstall.sh

八、文件结构
-----------
termux-pet/
├── pet.sh          # 主脚本
├── pet.conf        # 配置文件
├── dialogues.txt   # 对话文本库
├── install.sh      # 安装脚本
├── uninstall.sh    # 卸载脚本
└── 使用说明.txt     # 本说明文件

九、注意事项
-----------
1. 建议在 Termux 环境中使用
2. 支持 bash 和 zsh 终端
3. 宠物显示不会遮挡命令输入区域
4. 好感度数据自动保存，重启终端后保留
